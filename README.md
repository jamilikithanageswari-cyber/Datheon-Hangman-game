# Hangman Game – Python

## About the Project
This is a terminal-based Hangman game developed using Python as part of my Datheon Python Programming Internship.

The player needs to guess a randomly selected hidden word, one letter at a time, within six incorrect attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Tracks previously guessed letters
- Prevents duplicate guesses
- ASCII Hangman display
- Winning and losing messages

## Technologies Used
- Python
- Random module
- File handling
- Loops and conditional statements
- Sets

## Project Structure
```text
Datheon_Hangman_Game/
│

```

## How to Run the Project
1. Install Python.
2. Download or clone this repository.
3. Keep `hangman.py` and `words.txt` in the same folder.
4. Open the folder in VS Code.
5. Run the following command:

```bash
python hangman.py
```
